   → 等待绿色✓编译完成
   → 下载Artifacts中的FeishuAutoStatus-deb.zip

第3步：安装到iPhone
   □ 用爱思助手传.deb到Documents
   □ 用Filza打开并安装
   □ 重启SpringBoard: killall -9 SpringBoard

第4步：查看日志验证
   ssh root@iPhone-IP
   log stream --predicate 'processImagePath contains "Lark"' | grep FeishuAutoStatus

第5步：根据日志优化
   → 如果看到"✅ 找到状态管理类"，说明成功
   → 如果看到"🔍 发现可能的状态类: XXX"，告诉我类名
   → 我会更新代码并重新编译

💡 技术亮点
═══════════════════════════════════════════════════════════════

1. 跨平台逆向思路
   iOS越狱环境受阻 → Android ADB分析 → iOS类名映射
   关键发现：com.ss.android.lark.mine.impl.custom_status.UserCustomStatusActivity

2. 智能运行时适配
   - objc_copyClassList扫描所有类
   - 尝试6种可能的类名
   - NSInvocation动态调用10种方法签名
   - 失败时自动打印候选类供人工确认

3. 完善的工程化
   - Git规范提交
   - GitHub Actions CI/CD
   - 详细的中英文文档
   - 一键推送脚本
